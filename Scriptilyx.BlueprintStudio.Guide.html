BLUEPRINT STUDIO

A complete user guide for creating, editing, validating, importing, and exporting Space Engineers blueprints. This guide focuses entirely on using the application and building successfully.

Version 1.2.3 Platform Windows desktop Game Space Engineers Guide Offline and self-contained

Quick Start

  1. Choose the Space Engineers folder. Use the folder button near the top of the app and select the main Space Engineers installation folder.
  2. Create a new blueprint. Click the New button and choose the grid size you want to begin with.
  3. Find a block. Search or filter the Block Palette, then click a block to make it active.
  4. Place blocks in the viewport. Use the placement preview, rotate as needed, and click to place.
  5. Validate the blueprint. Correct any problems shown in Error List.
  6. Save and export. Save the editable project, then export a fresh blueprint to Space Engineers.
Recommended: Save the editable Scriptilyx project before every major change and before exporting to the game.

Interface Overview

Top command bar

Contains New, Open, Import, Save, Export, Undo, Redo, validation, folder selection, About, and Guide controls. Picture controls use PNG icons.

Block Palette

Searches and filters the available Space Engineers blocks. It is also the source for assigning blocks to the bottom toolbar.

Blueprint tabs

Each open blueprint has its own compact tab. Click a tab to switch projects and use its PNG close button to close it.

3D viewport

The main construction area. Orbit, pan, zoom, select, rotate, mirror, place, duplicate, delete, and inspect blocks here. The Show Grid control at the upper left turns the construction grid on or off.

Right-side panel

Contains Explorer, Properties, Lighting, and Statistics. The panel can be resized while its vertical picture-button strip remains docked. Mirror X, Mirror Y, and Mirror Z controls are located below Delete.

Output and Error List

Output reports activity and warnings. Error List reports validation issues and can locate the affected grid or block.

Projects and Blueprints

New project

Use New to create a blank blueprint. Give it a descriptive name and select the appropriate large- or small-grid starting point.

Open

Use Open for an editable Scriptilyx project that you saved earlier. The project retains the app’s grid, block, subgrid, and mechanical-connection information.

Import BP

Use Import BP to open an existing Space Engineers blueprint. Imported grids and blocks become editable inside the application.

Save and Save As

  • Save updates the current project file.
  • Save As creates a separate project copy under a new name or location.
  • An asterisk on a blueprint tab means the project has unsaved changes.
Important: The editable Scriptilyx project and the exported Space Engineers blueprint serve different purposes. Keep the project file so you can continue editing later.

Using the Block Palette

Search

Enter a block name, subtype, or category word. Click the PNG X button beside the search box to clear the search immediately.

Dropdown filters

All palette dropdowns begin on All. Narrow the list by category, grid size, DLC, or other available source filters.

Favorites

Use the PNG star beside a block to add or remove it from Favorites. Enable the Favorites filter when you want a shorter list of commonly used blocks.

Selecting a block

Left-click a palette item to make it the current placement block. The selected block name appears above the viewport.

Adding a block to the bottom toolbar

Right-click a palette block to assign it to the current toolbar page. When an empty toolbar slot has been selected first, the block is assigned to that slot. Otherwise, the first available slot is used.

Bottom Block Toolbar

The bottom toolbar provides fast access to frequently used blocks, similar to the in-game toolbar.

Grid display

Use Show Grid to turn the construction grid on or off. The construction grid stays on the chosen build grid while you click and inspect blocks. It changes when you choose another grid in Explorer or begin placing on another compatible subgrid, and it continues to follow that grid when a rotor, hinge, or piston moves it. The white occupied-cell outlines show the cells a block uses; the visible model may not fill every part of its occupied cells.

Selection

Switch to Select mode to inspect an existing block. Mechanical top parts use model-aware selection so you can choose the visible head even where its occupied cells overlap the base.

Placing and Editing Blocks

Basic placement

  1. Select a block from the palette or bottom toolbar.
  2. Move the pointer over the desired grid or visible build surface.
  3. Rotate the preview until the block faces the correct direction.
  4. Click to place it.

Delete

Select a block and use the PNG Delete button. Deleting the final block on an unused orphaned subgrid also removes the empty subgrid.

Duplicate

Select a block and use Duplicate to create a matching copy where supported. Move or place the copy in a valid open location.

Undo and redo

Use the top buttons or Ctrl + Z and Ctrl + Y. Undo can restore removed blocks, grids, and supported mechanical relationships.

Placement tip: When a placement preview appears on the wrong grid, select the intended grid or top-part subgrid in Blueprint Explorer before placing.

Grids and Subgrids

Main grids

A blueprint can contain multiple large and small grids. Use the Blueprint Structure tree and the grid buttons to add grids, select a build grid, and inspect mechanical relationships.

Static and dynamic grids

Static grids are generally used for stations. Dynamic grids are used for ships, vehicles, detached structures, and mechanical top-part subgrids.

Mechanical subgrids

A piston head, rotor head, hinge head, or suspension wheel exists on a separate dynamic grid connected to the base grid. Blocks built on that top part belong to its subgrid and move with it.

Explorer selection matters

The currently active build grid determines where ordinary palette blocks are added. Selecting a grid node changes the build grid. Selecting a block node only selects the block and does not move the visible construction grid.

Startup and Loading Screen

When the program starts, an animated loading screen remains visible while settings, Space Engineers block information, saved recovery data, and the editor workspace are prepared.

  • The circular indicator and status bars continue moving during startup.
  • The loading message changes as the program advances through each stage.
  • The percentage reflects the reported startup progress.
  • The main editor opens only after startup preparation has completed.

Mirror Placement

Mirror placement creates matching copies of a block across the selected grid’s origin planes. The three mirror controls are on the right-side picture-button strip below Delete.

  • Mirror X reflects placement across the X plane.
  • Mirror Y reflects placement across the Y plane.
  • Mirror Z reflects placement across the Z plane.
  • Multiple active axes can create four or eight matching placements.
  • The mirrored copies use mirrored positions and mirrored rotations.
  • A block directly on a mirror plane is not duplicated on top of itself.
  • Turn every mirror control off to return to normal single-block placement.
Preview first: The placement preview shows the mirrored copies and their rotations before you place them.

Pistons, Rotors, Hinges, Suspensions, and Wheels

The application supports standard pistons, Square Pistons, rotors, Advanced Rotors, hinges, suspension bases, and compatible wheel top parts on large and small grids.

Add Top Part

  1. Select the mechanical base.
  2. Click the PNG Add Top Part button.
  3. Choose one compatible head from the window.
  4. The app creates a dynamic top subgrid and links it to the selected base.

Choosing the correct part

The Add Top Part window filters incompatible choices. Some large-grid bases can support a small-grid top part. Choose the size and head style that match the result you need in Space Engineers.

Detach Top Part

Use Detach Top Part to break the mechanical relationship. The detached subgrid remains in the blueprint until you delete it or its final block.

Building on a top part

Click the visible top part or select its subgrid in Explorer. Blocks placed afterward use the visible top-part build surface rather than the taller base block’s occupied-cell box.

Wheel alignment

Suspension wheels use a suspension-specific hub position instead of the rotor and hinge face offset. The editor centers the rendered wheel model on that hub for both large- and small-grid suspensions.

Viewer position versus in-game position

The app displays mechanical heads using model-aware visual alignment. Export uses Space Engineers-compatible mechanical transforms so the game can recognize and snap the connection correctly.

After changing versions: For old projects containing a previously mismatched mechanical head, detach it and use Add Top Part again before exporting a fresh blueprint.

Explorer, Properties, and Statistics

Blueprint Explorer

Explorer is a true Blueprint Structure tree. Root grids appear at the top, mechanical subgrids are nested below their rotor, hinge, piston, or suspension base, and secondary mounts are labeled when two mechanical parts connect to the same grid. Selecting a grid changes the build grid; selecting a block only selects that block.

Tree movement tools

The lower Explorer tools can move the selected block one cell on X, Y, or Z. Drag an unconnected block row onto another same-size grid, or use Move to grid. Both methods preserve its approximate world position and orientation and reject occupied destinations. Mechanical bases and top parts must use Connect or Disconnect so their links remain valid.

Connection tools

Connect uses an explicit two-step selection shown in Explorer. Disconnect removes the selected mechanical link, separates a mounted top part from a shared grid when necessary, or extracts a normal block from a mechanical subgrid into its own independent grid.

Exact rotor and hinge angles

Select either endpoint of a connected rotor or hinge, enter the requested degrees in Rotor / Hinge Angle, and press Apply. The complete child subgrid rotates immediately, and undo or redo restores the previous value.

Properties

The Properties tab displays editable information for the selected item. Available values depend on the block and current application version.

Lighting

The Lighting tab adds and deletes up to eight editor-only point lights. Each light has an editable name, enabled state, world position, intensity, range, and RGB color. In Select mode, drag a light marker directly in the viewport to move it across the current view plane, use Shift + drag for world-vertical movement, or Ctrl + drag to move it toward or away from the camera. Viewport light moves support undo and redo. These lights are stored in the project and are not exported to Space Engineers.

Statistics

Statistics summarizes the blueprint, including grid and block counts and other available build information.

Resizable panel

Drag the divider beside the right panel to change its width. The vertical picture-button strip remains docked and does not stretch with the panel.

Validation

Run validation before every export. Validation identifies exact grids, blocks, positions, and reasons when something needs attention.

Common issues

  • Empty grids that should be deleted
  • Overlapping or invalid block positions
  • Missing or incompatible block definitions
  • Broken mechanical references
  • Unsupported grid or block relationships

Using Error List

Open the Error List tab, read the reason, and click Show to locate the affected item. Warnings may still allow export, while errors should be corrected first.

Output

When importing a blueprint, the program displays a small modal activity screen with an animated progress bar while the blueprint is read, its mechanical links are reconstructed, and the editor hierarchy is prepared. This is especially useful for large blueprints that take longer to open.

Output reports game-folder loading, definition loading, model warnings, save results, import results, export destinations, and help or link-opening errors.

Exporting to Space Engineers

Export to SE

Writes the current blueprint to the local Space Engineers blueprint directory. This is the fastest method when the game installation and user folders are detected correctly.

Export Folder

Writes the blueprint files to a folder you choose. Use this for backup, transfer, inspection, or manual installation.

Recommended export sequence

  1. Save the editable Scriptilyx project.
  2. Run Validate and correct all errors.
  3. Use Export to SE or Export Folder.
  4. Open the Space Engineers blueprint screen.
  5. Refresh the list when necessary and paste a fresh copy into the world.
  6. Test moving parts, orientation, and block availability.
Do not test an old export after making corrections. Export a new blueprint because earlier blueprint folders still contain their earlier positions and data.

Troubleshooting

Blocks or models do not load correctly

  • Confirm the selected folder is the main Space Engineers installation directory.
  • Check Output for missing model, texture, or definition messages.
  • Restart the app after changing the game folder when instructed.

A block is placed on the wrong level

  • Check the active grid in Blueprint Explorer.
  • Click the visible piston, rotor, or hinge top part before placing on it.
  • Remove the incorrect block and place it again on the intended subgrid.

A mechanical head is visually wrong in the app

  • Confirm the chosen head is compatible with the base.
  • Detach and re-add top parts created by much older app versions.
  • Export a fresh blueprint after correcting the connection.

The game snaps a part after pasting

Space Engineers can finalize recognized mechanical relationships after the blueprint is pasted. Check that the final in-game position is correct and that the part remains connected.

The guide does not open

The file Scriptilyx.BlueprintStudio.Guide.html must be located in the same directory as the executable. Rebuild or republish the app if it is missing.

A social link does not open

Confirm Windows has a default web browser. Any opening error appears in the About window status area.
